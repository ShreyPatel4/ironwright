From the old estate to answers you can trust

Every business in OntoForge goes through the same six steps. Each step makes a promise, and each promise has a test that runs on every build.

  1. 1

    Land

    Every file kept exactly as it arrived, every run kept.

  2. 2

    Check

    Writes go to a branch first. Bad rows are held back.

  3. 3

    Reconcile

    New numbers matched or explained against the old reports.

  4. 4

    Unify

    One object per real thing, with field-level provenance.

  5. 5

    Act

    Agents propose. Policy and people decide.

  6. 6

    Prove

    Evals at every layer, against planted ground truth.

Built for regulated work

One ontology, a different lens for every role. Designed first for healthcare and finance.

Lenses

Care, billing, compliance and agents see the same model through their own role.

Fields

Sensitive fields are masked by role, at read time.

Actions

Permissions per role, with limits and separation of duties.

Traceability

Every agent step: inputs, rule, model, approver.

Evidence

Access reviews and control tests straight from the audit log.

Run it yourself, free

Everything runs on a laptop with no keys and no cloud account.

pip install -e ".[dev]" ontoforge run --pack all # generate, migrate, reconcile, ontology, agents, evals ontoforge serve --pack retail # REST API ontoforge mcp --pack retail # MCP tools for any agent
